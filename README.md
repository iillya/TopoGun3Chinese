# TopoGun 3 中文汉化 1.0.0

为 Windows 版 TopoGun 3 提供中文界面，可随时切回英文。无需安装 Python 或翻译软件，日常使用不调用在线翻译服务。

## 安装与更新

1. 保存工程，正常退出所有 TopoGun 窗口。
2. 运行 `dist/TopoGunChineseInstaller.exe`，按提示允许安装。
3. 选择**包含 TopoGun.exe 的软件目录**，例如 `C:\Program Files\TopoGun 3`，不要选择其下的 ChineseLauncher 文件夹。
4. 按需创建桌面或开始菜单快捷方式。默认勾选“使用 TopoGun 中文版打开 .tgs 工程文件（当前用户）”，安装后可双击工程或从 **TopoGun 中文版** 启动。

更新时运行新版安装包，选择原来的安装目录即可。更新不会让已经打开的软件自动换成新版，因此务必先保存并退出。

补丁文件位于软件目录下的 `ChineseLauncher`，不会替换 TopoGun.exe 或原软件的 Qt DLL。选择文件关联后，`.tgs` 通过汉化启动器打开，保留原工程图标；其他格式不受影响。直接启动原来的 TopoGun.exe，可使用未加载汉化的原版。

文件关联沿用 EmberGen 中文补丁的方式：注册独立的中文工程类型，备份原默认关联，升级保留备份；取消关联选项或卸载时，仅恢复仍由补丁管理的关联。TopoGun 原来的打开命令不修改。关联作用于执行安装的账户，以匹配 TopoGun 原有的当前用户注册方式。

如果 Windows 仍提示选择应用，请右键 `.tgs` →“打开方式”→“选择其他应用”，选择 `ChineseLauncher\TopoGunChineseLauncher.exe` 并设为始终使用。Windows 已明确指定的默认应用不会被安装器强行覆盖；卸载后可能需要在系统中重新选择原版。

## 日常使用

| 操作 | 方法 |
| --- | --- |
| 切换中英文 | 点击菜单栏“中/英”，或按默认快捷键 F3 |
| 更改切换快捷键 | 右键点击“中/英”，点击录入按钮并按新键，再点“确定” |
| 恢复默认快捷键 | 在设置窗口点击“重置”，再点“确定” |
| 放弃本次设置 | 点击“取消”；录入过程中按 Esc 可停止录入 |
| 采集未翻译文本 | 打开相关界面后按 Shift + 反引号键（通常与 ~ 共用） |
| 打开作者主页 | 点击菜单栏蓝色署名链接 |

支持 F1–F24 等单键，F5、F6、F7 使用相同的优先级规则：只有当前设置的那个键优先用于切换，其他功能键保留给 TopoGun。

建议将切换键设为 F3、F5 等功能键。自定义快捷键只支持单键；设为字母、数字或编辑键时，该键可能优先用于语言切换，影响软件原来的输入或操作。设置窗口打开时暂停语言切换，以便录入新键。

快捷键保存在当前用户的 `%APPDATA%\TopoGunChinese\hotkeys.json`，下次启动继续使用；配置损坏时恢复 F3。

## 支持范围

- Windows 10/11，64 位 TopoGun 3。
- 兼容目标：**Qt 5.12 及以上的 Qt 5、MSVC x64**。不适配 Qt 5.6、Qt 6、MinGW 或 32 位版本。
- 无需自行安装、下载或替换 Qt。安装器检查 TopoGun 自带的组件，启动器进一步检查汉化所需接口。
- 本机 TopoGun 3 使用 Qt 5.12.5。其他 Qt 5 版本的接口检查通过，不等于已完成对应 TopoGun 版本的运行验证。

启动前发现接口缺失、补丁 DLL 缺失，或 DLL 加载失败时，启动器会尝试启动原版并说明原因。这不是运行时崩溃恢复功能；进入软件后发生的异常不能保证自动回退。

## 词典与翻译范围

当前正式词典含 **1,743 条**文本，涵盖菜单、工具、参数、提示和部分对话框。翻译在显示和文字测量环节生效，不把中文写回模型数据或原控件文本。

文字测量仅接入 Qt5Widgets 的界面排版调用；宿主程序自己的测量结果保持原文。绘制翻译覆盖控件及有可见控件上下文的 QStyle 离屏界面缓存，普通离屏图像、纹理和导出绘制保持原文。若特殊自绘界面无法判定与导出资产的区别，会优先保留英文。

词条数量不代表所有界面已经覆盖。动态拼接文字、包含变化数字的统计信息、特殊绘制界面和 Windows 原生标题栏仍可能显示英文。资源里有词条，也不代表每一种绘制方式都已验证。

已安装词典位于 `ChineseLauncher\translations`。程序读取该目录下所有以 `_zh.json` 结尾的文件，按文件名排序合并；相同英文键的非空译文以后读取的文件为准，空白译文会跳过。

自行补词时建议新增独立文件，例如 `zz_custom_zh.json`，不要直接修改随安装包更新的词典：

```json
{
  "schema": "sp-translation-v1",
  "id": "topogun-custom",
  "translations": {
    "Restore Defaults": "恢复默认设置"
  }
}
```

保存为 UTF-8，保留英文原文的标点和换行，修改后重启 TopoGun。升级、卸载前请自行备份自定义词典。

## 反馈漏译与问题

按采集快捷键后，结果保存到桌面的 `TopoGun_untranslated_zh.json`。重复采集会合并新词，并保留已经填写的译文；文件损坏或无法保存时会提示错误。

采集不是全程序自动扫描。它读取当前已创建的界面文字，部分未打开的窗口和自定义绘制文本无法直接获取。为了避免误收个人输入，不采集输入框中填写的内容；场景列表仍可能含有对象名称，分享文件前请检查。

反馈时请提供：

- TopoGun 的版本或 build 号、补丁版本；
- 未翻译或显示异常处的截图；
- 从启动到出现问题的操作步骤；
- 若已采集，附上采集 JSON。

## 常见问题

**启动后没有中文或新词条没生效**

确认从“TopoGun 中文版”启动，并已退出旧进程后重新打开。安装目录应与实际使用的 TopoGun 目录一致。检查 `ChineseLauncher\translations` 中是否有词典；新增文件必须以 `_zh.json` 结尾且 JSON 格式正确。

**按 F5 没有切换**

先关闭快捷键设置窗口，确认录入 F5 后点击了“确定”。在 TopoGun 窗口内测试；设置损坏时会恢复 F3。若仍无效，请提供当时焦点所在的面板和操作步骤。

**部分对话框仍是英文**

可能缺少完整词条，也可能是特殊绘制或原生窗口标题不经过现有翻译路径。请提供截图，不能只通过重复添加相同词条解决。

**启动器提示 Qt 不兼容或缺少接口**

请保留提示中的具体原因，并提供 TopoGun 版本。不要把其他软件的 Qt DLL 复制过来替换。

**软件异常或崩溃**

先保存可保存的工作，再通过原 TopoGun.exe 对照测试，并记录是否仅在加载汉化后出现。补丁不保证能恢复未保存的工程。

## 性能说明

词典在启动时读取；正常使用不做持续的磁盘扫描或联网翻译，也没有启用定时全量扫描。文字绘制与测量时仍会产生查询开销，切换语言时会刷新布局；手动采集大量列表时也可能短暂停顿。

重复文字会复用查询结果，包括未找到译文的文字；缓存达到容量后自动淘汰较少使用的条目，长文本不存入缓存。切回英文后立即跳过翻译查询。现有测试不能代表所有场景的帧率或长期内存占用，不承诺零性能开销。

## 卸载

保存工程并关闭 TopoGun，在 Windows“已安装的应用”中卸载 TopoGun 中文补丁。

**卸载会删除整个 ChineseLauncher 文件夹，包括自定义词典及其中的备份。请先把需要保留的文件复制到别处。** TopoGun 原程序和工程文件不会被卸载。桌面的采集文件及用户目录中的快捷键配置保留，可按需自行删除。
