# 1.0.0 性能复查（2026-09-25）

## 范围与结论

检查了词典加载、精确/归一化/省略文本查询、绘制和测宽入口、全局事件过滤、控件代理安装、语言切换、采集、模块扫描和启动等待。主要可重复开销在查询路径，已优化。正式词典保持 1,743 条，版本仍为 1.0.0。

## 本次修改

- 用原生 QString 的完整结果缓存替代 UTF-8 归一化缓存。精确、模糊匹配和未命中结果都可复用，减少重复编码转换和索引查询。
- 省略文本恢复单独缓存。先读取 QLabel 完整源文，再查省略缓存，避免两个控件的相同截断标题互相污染。
- 缓存使用 LRU 淘汰、成本预算及单条长度限制；键和值复制为独立紧凑存储。动态文字不会导致无限增长，也不会保存调用方临时缓冲指针。
- 英文状态的测宽入口立即返回，不再先遍历整段文字检测中文。
- 只有去除助记符或状态星号后文本发生变化，才执行第二次精确查询。
- 修复模糊匹配冲突时带星号的原文可能只显示 `*`；词典目录不存在时也清空旧省略索引。词典重新加载使所有线程的旧缓存失效。

## 查询测试

同机 MSVC `/O2`、Qt 5.12.5 x64，加载正式词典。每组先预热，重复 200,000 次调用，取 5 次的中位数。精确组遍历正式词条，模糊组转大写并加省略号，未命中组添加固定未知前缀，省略组取前 5 个字符。前后结果校验和一致。

| 场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 精确查询 | 60.09 ms | 7.93 ms |
| 归一化查询 | 220.87 ms | 9.61 ms |
| 未命中查询 | 205.60 ms | 8.59 ms |
| 省略文本绘制查询 | 201.89 ms | 11.52 ms |
| 纯数字绘制查询 | 4.33 ms | 4.57 ms |
| 英文状态测宽查询 | 13.45 ms | 1.12 ms |

这是预热后重复文字的查询测试，不含字体排版、真实绘制、复杂场景或 GPU 工作。不能把这些倍数视为 TopoGun 帧率提升。纯数字路径未改，微小时间差不据此判断回归。首次遇到新文字、超长文字和持续变化的文字仍有查询成本，缓存插入与淘汰本身也有成本。

普通缓存预算 1 MiB、省略缓存预算 256 KiB，每条成本包括源文与译文的 UTF-16 字节数和 128 字节元数据估算。每条源文/译文最多缓存 1,024 个 UTF-16 单元；因此条目上限分别不超过 8,192/2,048。预算按线程独立，不等于整个进程的实际内存占用。

## 其他路径

- 词典只在启动时读盘，启动器完成启动后退出。正常运行不联网翻译、不定时读盘。
- QApplication 启动等待每 100 ms 检查一次，有 300 秒上限，初始化派发后线程退出。
- 延迟模块轮询默认关闭。导入表安装扫描仍在初始化执行，未为优化更改挂钩覆盖。
- 控件代理只在 Show/Polish 和重新开启中文时检查；未恢复逐帧遍历全部控件。
- 全部控件遍历主要集中在启动、语言切换和手动采集。语言切换的测宽、布局更新和延迟重绘保留，以免出现旧宽度或残留画面。
- 字体宽度不按文本单独缓存：字体、DPI、排版标志都可能改变结果。保留实际字体测量及中文留白。
- 手动采集有菜单去重和 20,000 单元格预算，但自定义模型单次取值耗时不可控；这是手动操作可能短暂停顿的剩余点，不是持续后台消耗。

## 验证与边界

- 全部正式词条及空白、星号、助记符、大写/省略号变体，冷/热缓存结果一致。
- 20,000 种动态未命中文字验证容量与淘汰；超长文本不保留；临时原始缓冲修改后缓存键不受影响。
- 词典重载、负结果失效、省略结果失效、缺失目录、模糊冲突、中英切换、独立线程读取均通过。
- F1–F24、录入隔离、配置持久化及损坏回退通过。
- 独立隐藏 Windows 测试进程完成弹窗中英绘制与原文保留检查、快捷键窗口字体继承和无问号按钮检查。
- 正式编译打包通过。Qt 符号检查不等于对其他 TopoGun 版本完成实机验证。

未控制用户鼠标或关闭用户场景。尚未测量真实 TopoGun 的长期内存曲线与复杂模型交互帧率，因此不宣称零开销或全版本运行稳定。
