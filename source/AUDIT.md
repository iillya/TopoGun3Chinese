# 1.0.0 审核记录（2026-09-25）

最新性能复查与测试数据见 PERFORMANCE.md；下文早期的归一化缓存方案已由有界完整结果缓存替代。当前正式词典为 1,743 条。

## 已修复

- 采集过滤不再把带问号的正常提示当作 URL 排除。
- 输入框只采集占位提示，不读取用户输入值；场景模型文字仍可能包含对象名称。
- 采集文件使用 QSaveFile 原子保存；读取失败、格式错误、非字符串译文和写入失败均停止覆盖并反馈错误。
- 重复引用的菜单与模型只扫描一次；菜单循环引用有保护，模型采集总预算为 20,000 个单元格。
- 查询归一化缓存改为线程独立，最多 8,192 项，每项源文本限制 4,096 字节；跨线程读取的语言状态使用原子变量。
- 归一化碰撞不再依赖 unordered_map 的不确定迭代顺序；有冲突时保留精确匹配，不任意选取译文。
- 关闭翻译时绘制层立即退出查询，避免继续执行省略文本恢复扫描。
- 视图代理在 Show/Polish 阶段检查，不在每次 Paint/UpdateRequest 中重复检查；语言重新开启时补装新建控件的代理。
- 删除含可变 QPointer 排序键的视图集合；以现有代理类型识别是否已经安装，避免对象销毁后集合键变化。
- 语言切换保留用户窗口尺寸，不再对普通顶层窗口调用 adjustSize。
- 快捷键设置窗口关闭等待销毁期间不再创建第二个实例，避免旧实例清除新实例的共享状态。
- 启动器解析 LoadLibraryW 实际所属模块的偏移，兼容 Kernel32 转发到 KernelBase 的情况。
- 加载失败后确认本次新建的子进程已退出，才尝试启动原版；不操作已有编辑进程。

## 清理与规范

- 删除未启用的工程关联与旧关联迁移模块，移除安装脚本中不存在的 fileassoc 任务分支。
- 删除 Mari/Toolbag 专用安装适配分支、Qt6 模块选择分支和未使用的 GitHub 菜单状态。
- 安装器和启动器共用 Qt 组件版本检查；不再维护两套版本判断。
- 保留实际使用的绘制、测宽、代理和采集路径；保留默认关闭的延迟模块扫描后备能力。
- 正式词典未删减。用户 README 与开发构建说明分开。

## 验证

- 正式构建与 Inno 打包通过，版本 1.0.0。
- source/tests/run.bat：词典查询、问号/URL 筛选、英文状态、F5 ShortcutOverride、录入窗口排他、配置保存/损坏回退、缓存上限测试通过。
- 200,000 次精确查询微测试约 35 ms，仅反映测试机上的查询函数成本，不代表实际 UI 帧率或全插件开销。
- 隔离测试目录安装、卸载返回 0；卸载后 ChineseLauncher 不存在、测试 TopoGun.exe 保留。
- 1,680 条词典：无重复键，无空白译文；打包词典的哈希与源码词典相同。
- 当前插件对本机 Qt 5.12.5 和 Qt 5.15.2 MSVC x64 的必要导入接口检查通过。

## 未覆盖的运行风险

- 实际 TopoGun 完整交互、不同 DPI 和长时间 CPU/内存曲线尚未测量；没有据此声明全版本稳定或零开销。
- 早先的 Qt 离屏弹框测试在不加载插件时也出现访问异常，不能据该测试断定汉化绘制是否正确。实机截图已经证明部分功能工作，但不足以替代完整回归。
- 符号存在检查不验证 C++ ABI 和私有实现行为。绘制拦截仍应随具体 TopoGun 构建验证。
- DLL 成功加载不等同于后续 UI 初始化成功；原版回退针对加载前及 DLL 加载失败，不提供运行崩溃恢复。
- 自定义绘制、动态数值文本及原生标题栏仍可能漏译。
